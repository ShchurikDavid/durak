# Проверка безопасности 3.232

Дата: 5 октября 2026 года. Изменения подготовлены локально; рабочий сервер не обновлялся.

Проверены сервер Express/Socket.IO, сессии и регистрация, выдача игрового состояния, веб-интерфейс, мобильный сетевой клиент, Bluetooth и Android-конфигурация. Это проверка исходников и автоматических тестов, а не гарантия отсутствия всех уязвимостей и не внешний пентест. Для старых недостатков нельзя достоверно установить автора по текущему состоянию кода.

## Дополнительное усиление защиты

- Комнаты выводятся через DOM/textContent вместо сборки HTML из полей. Эксплуатация старого места при действующих ограничениях сервера не подтверждена.
- Добавлена Content Security Policy; разрешены собственные ресурсы и необходимые ресурсы Google Sign-In. Добавлена проверка HTTP(S)-схемы WebSocket Origin.
- Для серверной тасовки используется криптографический генератор случайных чисел вместо Math.random.
- Некорректный и слишком большой JSON получают безопасный ответ 400/413 без внутренних деталей.
- APK собирается как release с отключённой отладкой. Для совместимости обновления оставлен прежний сертификат подписи; отдельный ключ для публичного распространения потребует планирования миграции.

## Оставшиеся ограничения

- В полном дереве npm есть предупреждения о `braces <= 3.0.3` (GHSA-vfj7-8cjw-p6xm, чрезмерная рекурсия при обработке специально подготовленных шаблонов). Оно приходит через инструменты сборки React Native/Metro. На дату проверки исправленная версия в advisory не указана. Принудительное понижение React Native не применялось. Не следует подавать недоверенные шаблоны в инструменты сборки. Это не зависимость отдельного игрового сервера.
- `npm audit --omit=dev` в `deploy/server` сообщил **0 известных уязвимостей**. Это не покрывает ошибки собственного кода и ещё не опубликованные проблемы зависимостей.
- Сохранённая сессия имеет серверный срок действия. Выход из аккаунта или очистка данных отменяют сохранённый вход; выбор гостевого режима хранится отдельно и не требует повторного подтверждения при обычном запуске.
- Google-вход с реальным аккаунтом, физический Bluetooth и установка на телефон требуют отдельного испытания; локальная проверка не должна выдаваться за эти испытания.
