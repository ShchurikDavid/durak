# Дурак 3.232

Локальное обновление от 5 октября 2026 года. Предыдущая версия: 3.231, versionCode 14. Новая версия: 3.232, versionCode 15. Рабочий сайт и сервер не обновлялись.

## Изменения

- На первом запуске сайта и приложения показаны возможности аккаунта: профиль, история матчей и доступ к результатам с разных устройств. Можно сразу продолжить без регистрации.
- Выбор гостевого режима сохраняется отдельно от сессии. При следующем запуске повторно нажимать кнопку не нужно.
- В Android сессия восстанавливается из защищённого хранилища. Веб использует постоянную серверную cookie. Серверный срок действия сессии — 30 дней; явный выход отзывает токен.
- Motion используется на сайте для появления формы и перемещения карт. В Android применяется нативный Animated. Системная настройка уменьшения анимации учитывается.
- Используются исходные иконки проекта. Металлические компоненты MetalForge не добавлены: экспорт требует платного доступа.
- Исправления безопасности и оставшиеся ограничения перечислены в [отчёте](security-3.232.md).

## Проверено

- `npm run check`: ESLint, Prettier, TypeScript и 54 теста прошли.
- В браузере проверены первый вход, переход к регистрации и возврат, выбор гостя и перезагрузка страницы, размер экрана 390 × 844.
- Проверены локальная партия с двумя игроками, раздача и перемещение карты; ошибок JavaScript при этом не обнаружено.
- Серверный `npm audit --omit=dev`: 0 известных уязвимостей. Предупреждение в инструментах сборки React Native описано в отчёте.
- `assembleRelease` завершился успешно; APK имеет пакет `com.durak.game`, версию 3.232 (15), архитектуры arm64-v8a и x86_64, Android 8.0 и новее. Размер: 63 479 863 байта.
- `apksigner verify` подтвердил подпись. SHA-256 сертификата совпадает с предоставленным APK 3.231: `45982f0171b54eaf69bb3ef5920c152ba03930627e6f1e6aa5e16ad9501896c1`. Пакет можно устанавливать как обновление без удаления прежней версии.
- В собранном манифесте отладка не включена, cleartext и резервное копирование запрещены. Проверено совпадение хешей исходников Android, mobile и src между основной папкой и копией сборки.

Физический телефон, Bluetooth между двумя телефонами и реальный вход через Google в этой проверке не использовались.

## Сборка на этом компьютере

Из-за кириллицы в путях Windows для APK использована копия исходников в `C:\Users\Public\durak-build-3.232`. Изменения исходников остаются в основном репозитории. Для Android SDK и Gradle-кэша созданы локальные junction-пути с латинскими именами; установленные SDK и зависимости не заменялись.

Окружение PowerShell для сборки копии:

```powershell
$env:JAVA_HOME = 'C:\Program Files\Java\jdk-17'
$env:GRADLE_USER_HOME = 'C:\Users\Public\durak-gradle'
$env:JAVA_TOOL_OPTIONS = '-Djdk.net.unixdomain.tmpdir=C:\Users\Public\durak-build-temp -Djava.io.tmpdir=C:\Users\Public\durak-build-temp'
# Из каталога android в копии проекта:
.\gradlew.bat assembleRelease '-PreactNativeArchitectures=arm64-v8a,x86_64' --no-daemon --console=plain
```

В `android/local.properties`: `sdk.dir=C:/Users/Public/durak-android-sdk`. Артефакты находятся в `artifacts/` основного репозитория. Архив `durak-ubuntu-3.232.tar.gz` подготовлен локально для будущего обновления сервера; публикация не выполнялась.
