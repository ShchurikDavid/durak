# Дурак

Подкидной и переводной Дурак на 2–4 игроков: комнаты, приглашения, музыка и скины карт.
Работает в LAN и через Cloudflare Tunnel. Доступны колоды на 24, 36, 52 и 54 карты.
Первый отбой — до 5 атакующих карт, последующие — до 6.

## Запуск

Требуется Node.js 24 или новее.

```sh
npm ci
npm start
```

Сайт: http://localhost:3000. LAN-адреса печатаются в терминале.
Порт можно изменить переменной окружения `PORT`.

## Аккаунты и база данных

SQLite создаётся автоматически в `data/durak.sqlite`. Отдельный сервер базы данных
и дополнительные настройки для локального запуска не нужны. Путь можно изменить
переменной `DATABASE_PATH`. Каталог `data/` не попадает в Git; храните его на
постоянном диске. Для резервной копии остановите сервер и скопируйте весь каталог.

В лобби доступны регистрация по почте, нику и паролю, вход и выход из аккаунта.
Почта уникальна без учёта регистра; ник аккаунта используется в игре автоматически.
Старые аккаунты сохраняются: при входе можно указать прежний логин вместо почты.
Пароли хешируются с индивидуальной солью (scrypt), сессии действуют 30 дней и
сохраняются после перезапуска. В базе хранится только хеш токена сессии.
Восстановление пароля и подтверждение почты пока не предусмотрены.
Поле пароля имеет кнопку «Показать / Скрыть».
Также подготовлен вход через Google: [инструкция подключения](docs/google-login.md).

Можно играть без аккаунта и без ввода ника: по умолчанию используется «Игрок».
Гости и пользователи с аккаунтом меняют ник в «Настройки → Ник в игре» — в лобби
или прямо во время партии. Ник аккаунта сохраняется в базе, ник гостя — в браузере
и гостевой сессии. Новый ник сразу виден участникам текущей комнаты.

При публикации через HTTPS задайте `COOKIE_SECURE=true`, чтобы браузер передавал
cookie сессии только по HTTPS. Для обычного локального HTTP оставьте настройку
выключенной. Вход и регистрация ограничены 20 попытками за 15 минут с одного IP;
за обратным прокси без отдельной настройки IP этот лимит общий для его клиентов.
Игровые комнаты по-прежнему хранятся в памяти и исчезают после перезапуска.

Для доступа через интернет установите `cloudflared` и выполните:

```sh
cloudflared tunnel --url http://localhost:3000
```

В Windows также можно использовать `start-internet.bat`.

## Для разработчиков

Постоянный адрес: **https://game.durakcards.uk**. Запуск на этом ПК:
`start-domain.bat`. [Настройка домена и работа сервера](docs/domain.md).

Android-проект находится в `android/`. Откройте его в Android Studio.
[Сборка приложения и подключение по Wi-Fi](android/README.md).
Приложение на React Native имеет собственный интерфейс и встроенную игру с ботами:
для запуска и одиночной партии не нужны сайт, сервер или интернет.
Сетевые комнаты и аккаунты подключаются к игровому серверу по Wi-Fi или HTTPS.
Bluetooth позволяет играть на 2–4 телефонах без интернета и компьютера.
Игра по Wi-Fi с сервером на телефоне пока не реализована.

Начните с [архитектуры и карты файлов](docs/architecture.md).
Сведения о графике сохранены в [описании ресурсов](docs/assets.md).

- `npm test` — игровые и интеграционные тесты.
- `npm run lint` — проверка неопределённых переменных и недостижимого кода.
- `npm run format` — форматирование исходников.
- `npm run check` — все автоматические проверки.

`server.js` запускает приложение; серверные модули находятся в `src/`.
Разметка — в `public/index.html`, клиентские ES-модули — в `public/js/`,
стили — в `public/css/`. Сборщик не нужен. `package-lock.json` фиксирует зависимости.

## Игровые особенности

- Кнопка «Создать новую комнату» открывает окно выбора колоды, числа игроков и типа игры.
- В переводном режиме нажмите «Перевести» и выберите подсвеченную карту того же
  достоинства. Перевод доступен до первой карты защиты, если следующему игроку
  хватает карт для всей атаки. Джокером переводить нельзя; лимиты 5/6 сохраняются.
- Партия начинается, когда подключились все выбранные участники.
- При разрыве связи даётся 60 секунд на переподключение.
- Явный выход закрывает комнату; перезапуск сервера удаляет все комнаты.
- Красный джокер защищает красные карты, чёрный — чёрные. Джокерами нельзя атаковать.
- Настройки музыки, эффектов и колоды сохраняются в браузере.
- Карты находятся в `public/cards/`, значки — в `public/icons/`.

Чтобы добавить скин, положите изображения в `public/cards/<название>/` и дополните
каталог `SKINS` в `public/js/cards.js`. Имена карт: `AS.png`, `10H.png`,
`JOKER_RED.png`, `JOKER_BLACK.png`; путь к рубашке задаётся в каталоге.
