# Дурак — комнаты + LAN + Cloudflare

## Что изменилось

- Каждая партия живет в отдельной комнате.
- В комнате максимум 2 игрока.
- Несколько пар могут играть одновременно.
- Комнаты имеют короткий код, например `A7K2F`.
- Комнату можно создать, а сопернику отправить код или ссылку.
- После ухода последнего игрока пустая комната автоматически удаляется из списка.
- При обычном разрыве связи дается 60 секунд на переподключение.
- Игрок не может занять два места в одной комнате с одного `userId`: старое соединение отключается.
- Состояния игр разных комнат полностью разделены.
- Фоновая музыка — 3%.
- Работает по LAN и через Cloudflare Tunnel.

## Запуск

```bash
npm install
npm start
```

LAN: открой адрес, который покажет сервер, например `http://192.168.0.222:3000`.

## Интернет через Cloudflare

Установи `cloudflared`, затем:

```bash
cloudflared tunnel --url http://localhost:3000
```

Отправь сопернику полученную ссылку `https://....trycloudflare.com`.

## Как играть несколькими парами

1. Игрок 1 открывает сайт и нажимает **Создать новую комнату**.
2. Сайт показывает код комнаты.
3. Игрок 1 отправляет код/ссылку своей паре.
4. Вторая пара создает другую комнату.
5. Игры идут независимо друг от друга.

Если открыть ссылку с `?room=ABCDE`, сайт автоматически попробует войти в эту комнату.

## Очистка комнат

Пустые комнаты не хранятся бесконечно:
- когда последний игрок выходит из комнаты — комната удаляется сразу;
- если игрок просто потерял соединение, сервер дает 60 секунд на переподключение;
- после 60 секунд отключившийся игрок удаляется;
- если после этого игроков не осталось — комната удаляется.

Это предотвращает накопление старых комнат при работе через интернет.


### Комнаты на самом сайте

Комнаты создаются **прямо в браузере**, без команд в терминале. На главной странице есть:
- «Создать новую комнату»;
- вход по коду;
- список свободных комнат;
- «Пригласить» — копирует/открывает системное меню отправки ссылки на конкретную комнату.

В списке показываются только комнаты, которые ждут второго игрока. После заполнения комната скрывается из общего списка, но игрок с прямой ссылкой может переподключиться.

При явном выходе комната закрывается и удаляется из списка. При обрыве соединения действует окно переподключения 60 секунд; если игрок не вернулся, комната закрывается.


### Музыка и анимации
- Фоновая музыка остаётся на 3% громкости.
- Музыку теперь можно выключить **прямо на экране создания/выбора комнаты**.
- Настройка музыки сохраняется в браузере.
- Карты на игровом столе больше не «летают» и не подпрыгивают при каждом ходе — они появляются сразу на своём месте.
- Убрано движение карты при наведении на ПК, чтобы взаимодействие было спокойнее.

## Режимы игры

При создании комнаты можно выбрать один из режимов:

- **24 карты** — 9, 10, J, Q, K, A всех мастей.
- **36 карт** — 6, 7, 8, 9, 10, J, Q, K, A всех мастей.
- **52 карты** — стандартная колода от 2 до A.
- **52 карты + 2 джокера** — 52 обычные карты плюс красный и чёрный джокеры.

Выбранный режим сохраняется за комнатой. В списке открытых комнат и после входа отображается текущий режим. Второй игрок не может его изменить.

### Джокеры

В режиме **52 карты + 2 джокера**:
- 🔴 красный джокер бьёт любую красную карту (♥ ♦);
- ⚫ чёрный джокер бьёт любую чёрную карту (♠ ♣);
- джокер не может быть козырем;
- джокер не может побить другой джокер.

### Bicycle Classic — реальные изображения

В `public/cards/bicycle-classic/` добавлены обработанные фотографии реальных карт, предоставленные для проекта:
- A♠ Bicycle 808;
- J/Q/K всех четырех мастей;
- цветной и чёрно-белый Joker.

Фото выровнены, очищены и приведены к единому размеру 500×700 без генерации рисунка заново. Эти локальные изображения имеют приоритет в игре; для остальных карт пока используется существующий fallback Deck of Cards API. PlayingCardHub также подтверждает наличие индивидуальных изображений стандартной колоды, но предупреждает, что изображения колод принадлежат соответствующим правообладателям, поэтому для публичного релиза нужно отдельно проверить права на полный набор. 

### Карты Bicycle Classic
В текущей версии обычные числовые карты (2–10) сохранены такими же, как были раньше — они загружаются через Deck of Cards API. Локальные изображения Bicycle используются только для подготовленных A/J/Q/K и двух Joker, чтобы не менять привычный вид обычных карт.

## Card artwork

The game now uses one consistent 54-card visual set based on public-domain/CC0 artwork from AustinGabriel's Public-Domain-and-CC0-Playing-Cards repository. The set includes all 52 cards, two jokers, and blue/red backs. No user photographs are included. The source repository states that its assets are CC0/public domain and suitable for commercial and non-commercial use.

## Скины колоды (новое)

В игре три набора карт, переключаются на лету — в лобби кнопкой **🃏 Колода**
или в **⚙️ Настройки → Скин колоды**. Выбор сохраняется в браузере и влияет
только на вашу картинку: соперник видит свой скин.

- **Classic Clean** — колода, которая была раньше (остаётся по умолчанию);
- **Bicycle Rider Red** — классическая раскладка пипсов, двойная красная рамка, плетёная красная рубашка;
- **Bicycle Rider Blue** — то же в синем варианте.

Файлы лежат в `public/cards/<скин>/`: 52 карты, два джокера и рубашка
(`backs/`). Скины сгенерированы из CC0-графики, интернет для них не нужен.
Чтобы добавить свой набор, положите папку с такими же именами файлов
(`AS.png`, `10H.png`, `JOKER_RED.png`, `backs/main.png`) и добавьте запись
в объект `SKINS` в `public/index.html`.

## Интерфейс

- Карты крупнее на всех разрешениях.
- Верхняя панель переведена на сетку: код комнаты, статус и кнопка музыки больше не накладываются друг на друга; на телефоне код комнаты уходит в отдельную строку.
- Рука выкладывается одним рядом: при нехватке места карты наезжают друг на друга (индексы в левом верхнем углу остаются видны), при совсем большом количестве появляется горизонтальная прокрутка.
- Блок «В колоде / Козырь» на телефоне больше не слипается в кашу.
