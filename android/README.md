# Дурак для Android — React Native

Самостоятельное приложение для Android 8.0 и новее. Интерфейс, карты и игровой
движок входят в APK. Сайт, браузер и Metro для запуска не нужны.

## Возможности

- Быстрая игра без интернета: 1–3 бота, колоды 24/36/52/54, подкидной и переводной.
- Собственный мобильный дизайн: главный экран, игровой стол, комнаты и профиль.
- Зелёно-золотая палитра и три оформления карт как на сайте.
- Игровой экран без прокрутки: стол и рука подстраиваются под высоту телефона;
  в горизонтальной ориентации рука располагается рядом со столом.
- Рука с непрозрачными перекрывающимися картами; большие руки занимают несколько рядов.
- Настройки по шестерёнке в меню и за игровым столом: ник, музыка, эффекты,
  отдельная громкость, вибрация и оформление колоды. Всё сохраняется на телефоне.
- Фоновая музыка сайта и звуки карт встроены в APK; при сворачивании звук приостанавливается.
- Сетевые комнаты через существующий Node-сервер по локальному Wi-Fi или HTTPS.
- Вход и регистрация по почте на выбранном сервере; пароль можно показать глазиком.
- Тайм-аут, перевод, сдача и повторная партия по общим правилам игры.

По Bluetooth создатель стола ведёт игру на своём телефоне: компьютер, интернет и
аккаунт не нужны. Нативный Google-вход и Wi-Fi-сервер на телефоне пока не реализованы.
Аккаунты хранятся на выбранном сетевом сервере. Незавершённая партия не восстанавливается
после закрытия процесса приложения.

## Игра по Bluetooth

1. Установите одинаковую новую версию APK на 2–4 Android-телефона.
2. На первом телефоне выберите «По Bluetooth» → «Создать стол», задайте число
   участников и правила. Разрешите Bluetooth и видимость телефона.
3. На остальных выберите «По Bluetooth» → «Найти друга / повторить поиск».
   Выберите имя телефона создателя, показанное на его игровом экране.
4. При запросе Android подтвердите сопряжение на обоих устройствах.
5. Раздача начинается автоматически, когда подключится выбранное число игроков.

Поиск работает как в версии 2.4: сразу показывает ранее сопряжённые устройства,
а новые добавляет по мере обнаружения, без проверки сервиса комнаты через SDP.
По умолчанию включён фильтр «Только телефоны» по классу Bluetooth-устройства.
Если телефон друга не появился, выключите фильтр: не все модели сообщают свой тип.
Устройства в списке не обязательно доступны сейчас или имеют открытую комнату;
выбирайте телефон друга, который создал стол. Длинные имена сокращаются в интерфейсе.
Общий поиск ограничен 30 секундами и завершается раньше по сигналу Android.
Когда все места заняты, ведущий закрывает слушающий
сокет и убирает объявление комнаты, сохраняя текущие соединения. Видимость создателя длится
5 минут; продлить её можно кнопкой «Как подключиться» на экране ожидания.
На Android 12+ используется разрешение «Устройства поблизости». На Android 8–11
для поиска нужно разрешение геолокации и включённая геолокация в системе.
Приложение не запрашивает координаты и не передаёт их.

Оставайтесь в приложении во время партии. Экран поддерживается включённым, пока
активно соединение. Если участник выходит или связь обрывается во время игры,
партия закрывается для всех; автоматического восстановления этой партии пока нет.
В комнате ожидания отключившийся участник освобождает место для другого.

Транспорт — защищённый Bluetooth Classic RFCOMM с UUID сервиса приложения,
JSON-сообщениями, границей 64 КиБ на сообщение и отдельными потоками ввода/вывода.
Ходы проверяет общий движок на телефоне создателя; каждому игроку отправляется
только его личная рука и публичное состояние. Время клиента корректируется при
отображении срока хода. Разрешения описаны в
[документации Android](https://developer.android.com/develop/connectivity/bluetooth/bt-permissions).

Автотесты проверяют 2–4 участников, обмен ходами, приватность рук, неподходящие
сообщения, выход из ожидания, отказ в разрешениях и очистку подписок. Радиосвязь,
системные окна сопряжения и поведение конкретных моделей требуют проверки на
реальных телефонах; локальная сборка и тесты не заменяют этот тест.

## Сборка

Нужны Node.js 24+, JDK 17, Android SDK Platform 37, Build Tools 37.0.0,
NDK 27.1.12297006 и CMake 3.22.1. Версии закреплены в проекте; зависимости
устанавливаются командой `npm ci` из корня репозитория.

На этом Windows-компьютере запустите из корня:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File android/build-debug.ps1
```

Скрипт использует установленный JDK 17 и SDK, копирует исходники в
`C:\Users\Public\durak-native-build`, создаёт ссылки на SDK и Gradle-кэш с ASCII-путями
и собирает APK для arm64-телефонов и x86_64-эмулятора. Это обходит ограничения
Android C++-инструментов на кириллицу и пробелы в пути. Результат копируется обратно:

`android/app/build/outputs/apk/debug/app-debug.apk`

Это отладочная подписанная сборка для установки вручную. Для публикации в магазине
нужны отдельная release-подпись и настройки выпуска. Пароли и ключи выпуска в
репозиторий не добавляйте.

Для Android Studio после первой сборки откройте
`C:\Users\Public\durak-native-build\android`, выберите JDK 17 для Gradle и запустите
приложение на устройстве. Редактируйте исходный репозиторий; повторный запуск скрипта
обновит копию для сборки. На системах с подходящими путями можно открыть `android/`
напрямую и выполнить `gradlew assembleDebug`.

Бандл включается даже в debug APK (`debuggableVariants = []`), а загрузка из Metro
отключена в `MainApplication.kt`. Поэтому установленная игра открывается самостоятельно.

## Комнаты через интернет

1. На компьютере запустите `start-domain.bat` и оставьте его работающим.
2. Подключите телефоны к интернету.
3. Откройте «Комнаты»: приложение само подключится к `https://game.durakcards.uk`.
4. Один игрок создаёт комнату, остальные выбирают её или вводят код.

Адрес закреплён в приложении; ранее сохранённый адрес не используется.
При неудаче первого запроса повторная попытка выполняется через 5 секунд.
После установления соединения переподключением управляет Socket.IO.
Выбор игры с ботами или Bluetooth закрывает интернет-сессию и её повторные попытки.

## Исходники и проверки

- `mobile/App.tsx`, `mobile/styles.ts` — нативный интерфейс и стили.
- `mobile/local-game.js` — офлайн-сессия и боты поверх общих игровых правил.
- `mobile/network.ts` — аккаунты и сетевые комнаты.
- `mobile/bluetooth.ts`, `mobile/bluetooth-host.js`, `GameBluetoothModule.kt` — Bluetooth-сессии, ведущий и Android-транспорт.
- `mobile/hand-layout.js` — раскладка руки; `mobile/cards.ts` и `mobile/assets/cards/` — встроенные колоды.
- `mobile/audio.ts` и `GameAudioModule.kt` — музыка, эффекты, аудиофокус и жизненный цикл Android.
- `src/game/`, `src/socket/handlers.js` — общий движок сайта и Android.
- `npm run check` — линтер, форматирование, TypeScript и автоматические тесты.

Офлайн-тесты проходят партии всех колод, обоих вариантов правил и 2–4 игроков;
интеграционный тест подключает два мобильных клиента к настоящему серверу и
проверяет комнату, смену ника и регистрацию. Визуальную проверку APK выполняйте
на телефоне или Android-эмуляторе.
